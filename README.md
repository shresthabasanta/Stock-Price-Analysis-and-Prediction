# Stock-Price-Analysis-and-Prediction
The aim of the current project is to examine and predict the prices of Apple Inc. (AAPL) stocks using Machine Learning and Deep Learning methodologies. Data regarding the historical trends in the stock markets were obtained from Yahoo Finance and analyzed using the Python programming language.
Objectives:
Analyse historical Apple stock market data.
Perform data cleaning and preprocessing.
Apply feature engineering techniques.
Develop and compare Linear Regression and LSTM models.
Evaluate prediction performance using RMSE and MAE.
Visualize insights and predictions using Power BI.

Tools & Technologies:
Python
Pandas
NumPy
Scikit-learn
TensorFlow / Keras
Matplotlib
Power BI
Yahoo Finance API (yfinance)

Key Features:
Historical stock price analysis
Data preprocessing and feature engineering
Exploratory Data Analysis (EDA)
Stock price prediction using Linear Regression
Stock price prediction using LSTM
Interactive Power BI dashboards
Model performance evaluation

Results:

The LSTM model outperformed the Linear Regression model by providing more accurate stock price predictions and better capturing market trends and volatility.
